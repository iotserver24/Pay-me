# PayMe Frontend

The modern, responsive frontend for PayMe, built with **Next.js 14** and **Tailwind CSS**. It provides the user interface for making payments and the admin dashboard for managing them.

## 🎨 Features

* **Payment Page**: A beautiful, conversion-optimized page for users to complete payments (`/pay/[id]`).
* **Admin Dashboard**: Secure interface to view and filter transaction history.
* **API Docs Page**: Built-in interactive API documentation (`/admin/api`).
* **Proxy Middleware**: Proxies public API requests to the backend to simplify CORS and integration.

## 🛠 Setup & Deployment

For detailed instructions on how to configure environment variables (`.env`), build the application, and deploy to Vercel or Netlify, please refer to the main **[Hosting Guide](../docs/HOSTING.md)**.

## 📦 Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev
```
